## 使用说明
本系统在第一次运行时会自动创建novel_data.json文件，同时创建唯一管理员“马剃天爱星”，**可以通过账号:admin，密码：0314（七海千秋的生日）进入**。当然为了更好的体验，仓库中已经有了一份本人设计的novel_data.json，里面已经有了用户小鞠、娜娜米、东南黑子，当然你也可以自己注册，已有账号的密码和账号一样（**给一个测试账号：213770001，密码：213770001**），账号明文存在了novel_data.json文件中,如果觉得账号记不住，可以修改hashPassword（）函数，使得密码也是明文存储。

进入系统之后，你可以看到主窗口下有许多不同的栏目，其实功能很简单，自己试试就知道个大概了，并且在这份文件夹中，已经有一份关于使用的报告了，可以自行阅读，这里粘贴部分关于主要功能的内容：

1.**学生使用姓名、学号和密码注册，之后用学号和密码登录**；**管理员账号由系统首次启动时自动建立**（采用admin登录，用户名为“马剃天爱星”，当然这只是个人的喜好罢了），管理员和学生进入不同的功能页面(比如学生就没有处理举报的栏目)；

2.**系统要求能够发布文章**：学生输入标题和正文进行投稿，投稿时系统自动检查标题和正文是否命中违禁词，未命中则文章进入“待审核”，命中则提交失败且不改变原有数据；

3.**系统要求作者能够修改自己的文章**：合法修改后文章重新进入“待审核”，命中违禁词的非法修改不会覆盖旧版本（但是如果旧版本有新加入的违禁词，旧版本不会撤回）；

4.**系统要求管理员能够进行审核管理**：对“待审核”文章通过或驳回（通过时使用最新违禁词表复查），对已公开文章进行撤回；对"待处理"举报进行标记处理，并可选择在处理时连带撤回被举报文章；

5.**系统要求能够增加和删除数据对象**：管理员可添加或删除违禁词；管理员还可通过“文章清理”栏目，按条件筛选出过期文章并将其连同举报记录一并删除；学生可注册新账号；学生对已公开文章可点赞、取消点赞或举报不良内容；

6.**系统要求能够进行基本查询**：文章广场支持按标题或作者姓名搜索已公开文章，审核页与举报页支持按状态筛选；“文章清理”栏目支持按状态、更新日期与作者组合筛选，并实时显示结果计数；

7.**系统要求能够输入和存储数据**：用户账号、文章、举报记录和违禁词统一保存在本机的novel_data.json文件中；

8.**系统要求能够显示数据**：显示全部已公开文章、当前账号的文章及其状态、待审核文章列表、举报列表和违禁词列表、已公开文章的点赞排行前三名，并实时显示搜索结果计数与状态栏统计；

9.**系统要求数据安全与正确性**：表格支持点击表头排序，排序或筛选后执行阅读、点赞、举报、审核、删除等操作时仍指向正确的目标文章。

ps：由于目前能力有限，该项目只支持单机模拟多账号登录，并且无法做到数据库同步，不过Shuning同学会继续努力哒！
